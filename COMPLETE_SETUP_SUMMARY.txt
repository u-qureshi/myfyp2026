TABLE 3: settings
   - id (UUID, primary key)

   - value (JSONB)
   - created_at, updated_at

TABLE 4: metrics
   - id (UUID, primary key)
   - user_id (foreign key)
   - event_type

   - created_at

TABLE 5: students
   - id (UUID, primary key)
   - user_id (foreign key)
   - name

   - created_at, updated_at

TABLE 6: faculty
   - id (UUID, primary key)
   - user_id (foreign key)
   - name
   - email

   - created_at, updated_at

TABLE 7: rooms
   - id (UUID, primary key)
   - user_id (foreign key)
