================================================================================
                          AUTHENTICATION FLOW
================================================================================

LOGIN FLOW:
  1. User selects role (Admin/Faculty/Student) from dropdown
  2. User enters email and password
  3. System calls /api/auth/login
  4. On success:
     - Token saved to localStorage.adminToken
     - Role saved to localStorage.userRole
     - User redirected to role-specific dashboard:
       • Admin → /dashboard
       • Faculty → /faculty-dashboard
       • Student → /student-dashboard

SIGNUP FLOW:
  1. User clicks "Sign Up" on login page
  2. User selects role from dropdown
  3. User enters name, email, and password
  4. System calls /api/auth/signup with role parameter
  5. Backend creates user with specified role
  6. On success:
     - Token saved to localStorage.adminToken
     - Role saved to localStorage.userRole
     - User redirected to role-specific dashboard

SESSION PERSISTENCE:
  1. User closes and reopens browser
  2. App checks localStorage.adminToken and localStorage.userRole
  3. If both exist and valid:
     - User marked as authenticated
     - User redirected to role-specific dashboard
  4. If missing:
     - User shown login page

LOGOUT:
  1. User clicks Logout button in sidebar
  2. localStorage.adminToken cleared
  3. localStorage.userRole cleared
  4. All state variables reset
  5. User redirected to login page
